Re-run the price list

The 2026 price list loads from a script that ships with the backend, so it can be re-run whenever the printed list changes: 

python scripts/import_pricelist.py
python scripts/import_pricelist.py --prices

The first adds or refreshes price-list products; the second only updates rates. Edit data/pl_products.json to change what they load. Products you added by hand are never touched.
